# Racccoon
Racccoon (with 3c) is a little toy kernel for riscv 32 bit architecture, written in C3.

Racccoon is also a little experiment to test the capabilities of the [C3 language](https://c3-lang.org/) regarding kernel and bare-metal developing.

Racccoon is heavly inspired, if not follows it, the guide [OS in 1.000 Lines](https://operating-system-in-1000-lines.vercel.app/en/).
